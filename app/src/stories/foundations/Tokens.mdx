# Tokens

Every value on this page is imported from `shared-theme/themePrimitives.ts` at build time, so it always matches the code. `AppTheme` turns them into CSS variables prefixed `--template-` and switches light and dark with the `data-mui-color-scheme` attribute.

<a href={figmaUrl('0:1')} target="_blank" rel="noreferrer">Open the Foundations page in Figma</a> · Rules for using these tokens: `app/src/design-system.md`.

## Differences from the Figma file

The Figma variables mirror these tokens, with these exceptions:

- Figma has a `components` collection (48 variables named after override paths, such as `MuiChip/success/backgroundColor`), `StatCard/trendColors/*` and `palette/action/disabled`. These are values inside component overrides or MUI defaults, not tokens in `themePrimitives.ts`, so they are not shown above.
- Figma spacing variables are named `spacing/0-25`, `spacing/1-5` and so on (Figma does not allow `.` in names) for `theme.spacing(0.25)` and `theme.spacing(1.5)`.
- `palette.baseShadow` is one value per color scheme in code; Figma has two effect styles, `shadows/baseShadow/light` and `shadows/baseShadow/dark`.
- Figma text styles fill in MUI default line heights where the code does not set one.
